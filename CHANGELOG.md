# Changelog

## 1.0.0 — First public beta

- Automatic project and timeline tracking, project manager pause, idle and foreground detection, crash checkpoints and compatibility checks.
- Linked and Resident launch profiles for Windows and macOS; manual history review, mini timer and hide to tray.
- Retry stale startup connections and restart the isolated probe after repeated API failures. Resume after returning to Resolve without requiring a new input event if still within the idle limit.
- Switch UI language immediately without resetting the current session. Independent invoice languages, 20 UI locales, 53 currencies and historical rates.
- Nine themes, Steel as default, vector Stintory branding and multi-resolution icons.
- PDF invoices, CSV/HTML reports, source installers, license notices and English documentation.

Windows Linked was tested by the maintainer during private development; this public beta still needs native retesting. Other profiles are experimental.
