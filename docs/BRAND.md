# Stintory identity

Stintory uses an original two-track timeline symbol redrawn from the selected concept. Its central playhead and lower highlighted clip use steel blue. The lowercase wordmark ends in a rounded period without a tagline. The full lockup and wordmark are outlined SVG artwork (no font runtime dependency).

Assets: `resolve_edit_tracker/assets/` contains `logo.svg` (dark backgrounds), `logo-light.svg` (light backgrounds), `wordmark.svg`, `symbol.svg`, `app.svg`, `tray.svg`, high-resolution transparent PNGs, and a multi-resolution ICO. `docs/brand-banner.svg` is the GitHub header. Tray artwork deliberately uses larger strokes and fewer tiny features. Windows shortcut, Tk window, native build and macOS launcher use the new icon. The PDF header uses the high-resolution light logo.

Steel is the new default theme. Existing explicit theme preferences remain intact. Neutral charcoal surfaces: #1B1B1D / #252527; blue accent #86B9E7, light variant #4B83B7. Other eight themes remain available.

Lettering: Inter by the Inter Project Authors, outlined as artwork; no font software is distributed. See CREDITS.md. The wordmark uses Inter outlines under OFL 1.1 (https://github.com/rsms/inter/blob/master/LICENSE.txt); the OFL permits logo artwork without redistributing font software (https://openfontlicense.org/). The name and artwork have not undergone formal trademark clearance.
