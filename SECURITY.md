# Security and privacy

Stintory processes project and timeline names, session timestamps, rates, and local activity state. No keystroke content or footage is recorded. The app does not transmit those records. Dependencies are downloaded at setup; the optional Resolve scripting connection is local. Keep External scripting set to Local rather than Network.

Report vulnerabilities privately using GitHub's private vulnerability reporting if enabled. If unavailable, open a minimal issue requesting a private channel without attaching exploit details or confidential logs. Never publish client data or account credentials.

History and settings are plain local JSON, not encrypted by Stintory. Use OS disk encryption and backups if needed. Verify source and downloaded dependencies before running; unsigned source preview packages are not production-signed releases.
