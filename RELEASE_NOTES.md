# Stintory 1.0.0 — Public Beta

First public beta of Stintory, automatic time tracking for DaVinci Resolve Studio. Includes project/timeline tracking, manual history review, mini timer and tray mode, nine themes, 20 languages, 53 currencies, PDF invoices and CSV/HTML exports. Language changes apply immediately. Startup connection retries are independent of dashboard visibility.

Windows Linked has user-reported hands-on testing during private development with Resolve Studio 21; please retest this release including hiding the window during Resolve startup. Windows Resident and macOS profiles remain experimental. Future Resolve versions are not guaranteed compatible. Source installers are provided, not signed executables. See README and docs/TEST-RESULTS.md for validation details.
